## Consistency calculation

Write ratios explicitly. If a 28 cm object is called “shorter than the forearm,” record the assumed forearm length. If the assumptions do not make both statements true, change the canon rather than carrying both into prompts.

The audience must be able to perceive the scale anchor. A dimension stated only in prose is not an observable contract.
