- Live-traffic windows observed today ranged **2.0–4.3** (4.275 just
  before run 2; 2.05–3.475 otherwise) — traffic-dependent and noisy.

  (run 2). `spec_num_draft_tokens` 8 throughout.
- 08-18 reference: DSpark on the *same probe cells* read **3.45**
  (3.575 live). So on the controlled cells the draft is ~30 % below
  DSpark; on live traffic it is in DSpark's neighborhood (the shared

  carry — the dropped convs/selector look like the delta).
- The card's **4.1–5.5** acceptance was **never reached in a
  probe-controlled window** — consistent with the missing conv/selector
code below.

## Why DFlash 2 underperforms here (root cause, verified 2026-08-19)

The pinned SGLang image **predates DFlash 2**. The card mandates
`sglang @ PR #35371` (still open); the image build `g561c8f3` ships only
the DFlash **v1** model class:

- Image `models/dflash.py` (589 lines): `DFlashAttention/MLP/DecoderLayer/
  DraftModel` + Laguna variants. PR #35371's `dflash.py` (1000 lines)
  adds `DFlashGroupedConv`, `CandidateSelector`, `DFlash2DraftModel`.
- The checkpoint carries **23 DFlash 2-specific tensors** the v1 class has
  no module for: `candidate_selector.{hidden_projection.weight,
  predecessor_codebook, successor_codebook}` and
  `layers.{0..4}.{attention,mlp}_conv.{base_kernel,
  kernel_projection.weight}`. The loader **silently drops all 23** (no
  warning in the boot log).
- Net effect: the surgery copy loads as a *crippled v1 draft* — backbone
  only, no dynamic convs, no candidate selector, v1 sampling. It is
  **lossless and functional** (boot log clean, verify CUDA graphs
  captured, completions correct) but drafts at ~2.0–2.4 acceptance on the
  controlled cells (DSpark: 3.45) instead of the card's 4.1–5.5 — i.e.
  measurably *below* DSpark.

**The fix is engine code, not flags.** Two paths:

1. **vLLM PR image** (in build 2026-08-19, `peterstorm/vllm:
   qwen38-dflash2-pr52816-19c9351`): vllm #52816 *natively registers*
   `DFlash2DraftModel` — no surgery, the card's exact config
   (`method: dflash`, `num_speculative_tokens: 7`). First clean number
   for real DFlash 2.
2. **SGLang PR-#35371 overlay** on the pinned image: the PR is
   python-only (`models/dflash.py`, `speculative/dflash_worker_v2.py`,
   `speculative/dflash_utils.py`,
   `model_runner_components/spec_aux_hidden_state.py`). Feasible as a
   thin overlay, but the PR's base is newer than `g561c8f3` — needs a
   compatibility pass and a validation boot before it earns a pin.

**Operational consequence:** until one of those images lands, DSpark v2
remains the fastest drafter on this box; the dflash2 SGLang profile
stays available for A/B but should not be read as a DFlash 2 performance
baseline.
